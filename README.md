# Expensive.trackerr
A Java-based console Expense Tracker application that allows users to register, log in, record income and expenses, and view financial summaries. The project uses object-oriented principles and file handling to store data persistently.
# Expense Tracker (Java)

A console-based Expense Tracker application developed using Core Java.

## Features
- User Registration & Login
- Add Income and Expenses
- Category-wise tracking
- View total income, expense, and balance
- Data persistence using file serialization

## Technologies Used
- Java (Core Java)
- OOP Concepts
- File Handling
- Collections Framework

## How to Run
1. Compile the program:
   javac ExpenseTracker.java
2. Run:
   java ExpenseTracker
